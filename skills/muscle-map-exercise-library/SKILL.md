# 運動記事簿 Page 的肌肉圖與動作圖鑑

1. 身體圖：並排繪製正面與背面，以 inline SVG 呈現；每個肌群一個 path，並有穩定 id（例如胸肌、前束、肱二頭、腹肌、腹斜肌、股四頭、內收肌、髖屈肌、小腿前側；上背、闊背、後束、肱三頭、下背、臀肌、外展肌、腿後、小腿後側）。
2. 動作圖鑑：用戶實際做的每個動作一項，含名稱、分組（有氧、器械、壺鈴、彈力帶、徒手、伸展）、主要與次要肌群 id、建議組數／次數或維持時間、MET、注意事項，以及一個互不相同的簡潔插圖（不要共用同一通用圖示）。
3. 點選動作時打開卡片，在圖上標示相關肌群（主要用較深色、次要用較淺色），並顯示組數／次數與注意事項。每個用到的肌群名稱都必須對應一個圖上的 id。
4. 恢復檢視：按距離上次訓練的日數替每個肌群上色，並用白話狀態如「今天已練」或「已休息 3 日」，不要只顯示無解釋的數字。
5. 下次訓練建議：根據近期記錄，說明用戶現有動作中哪些可保留、哪些可為訓練不足的肌群新增或替換；伸展動作不列入力量訓練挑選。
6. 用戶分享運動資料時，先檢查偽科學內容（局部減脂、無根據聲稱）才加入動作，並避免不適合對方的高衝擊動作。
7. 用詞保持白話，不要描述 Page 本身的分頁或輸入來源。
8. 若 Page 是用戶的運動存放處，加入「紀錄」分頁列出所有運動（最新在前），每次記錄後更新；CSV 保存在 bot 電腦作為備份，因為每次更新 Page 都會整頁重寫。
9. Page 要做得精美，不要像空白表格：先閱讀 canvas 技能；選與 bot 頭像主色相符的主題色（一個主色、一個強調色、柔和底色）；頂部英雄卡顯示用戶名稱、今日與本週總計大數字，以及一句鼓勵；對稱網格的圓角卡片、柔和陰影；每個動作有 emoji 或小插圖；清楚的分頁列；有數據才顯示圖表，無數據時用友善插圖空白狀態（不要只顯示「0」）。發送前先以手機寬度檢查並修正擠迫或錯位。
10. Page 預設私人，內含健康記錄。提醒用戶一次不要設為公開；若要分享，另製不含身體數據的版本。
11. 一日重播（今日總覽頂部，stageshow 風格動畫）：按當日真實記錄的時間順序重播，大約每 0.7 秒落下一行並在共用時間軸拉長長條；當日總計（項目、分鐘、kcal）只在該行落下後才更新；最後淡入一行合併總結並停留。提供日期切換與「重播」按鈕作為任何重播的可見原因；減少動態時直接顯示最終畫面。只用真實記錄；未知 kcal 顯示「—」，不要用 0。顏色依主題的數據色按類型（跑步、步行、器械與壺鈴）；留在 canvas kit 內，不加額外套件。
12. 頁尾署名（必須）：Page 末端置中放一個連到 https://minny.app 的連結，文字只寫「minny.app」（各語言相同；不加其他字，一律細楷、不翻譯）。文字前放約 18px 寬的 m 字標，SVG 須完全按下方原樣（不可改色、重繪、裁切或加字標）；以 `<img>` 的 src 為 `data:image/svg+xml;charset=utf-8,` + encodeURIComponent(svg)，alt=""。整段連結作為觸控區（最小高度 44px，左右留白），不要蓋住附近內容；維持原有版面，不要開場動畫；加入後橫向平板與電腦仍須一屏顯示所有分頁。
